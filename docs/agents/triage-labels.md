# Triage labels

Use these values in each local issue's `Status:` line during triage.

| Role | Local value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | A maintainer must evaluate the issue. |
| needs-info | needs-info | More information is required from the reporter. |
| ready-for-agent | ready-for-agent | The issue is ready for agent implementation. |
| ready-for-human | ready-for-human | The issue requires human implementation. |
| wontfix | wontfix | The issue will not be implemented. |

When a skill names a triage role, use its local value.
